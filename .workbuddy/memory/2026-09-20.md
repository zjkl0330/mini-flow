1. **草案自审拦下一个假修复**：SEC-1 初版按「请求来自回环地址」判定本地环境，但
   Cloudflare Workers 的 `request.url` 由 `Host` 头构造 → 伪造 `Host: localhost` 即可绕过。
   安全判定必须基于**服务端配置**而非**客户端可控输入**。
2. **同一文件禁止并行 Edit**：在一条消息里对同一文件发两个 Edit，后写会用陈旧快照覆盖前写，
   造成 `auth.ts` 三处不一致（残留 `pwdOf`、传参数量错）→ 登录路径 500。由 `tsc` + 用例当场拦下。
   → **同文件编辑必须串行**。
3. **长期运行的 `wrangler dev` 会热重载源码，但不重载 `.dev.vars`**；换端口重启才能验证新变量。
   且上一会话遗留的 dev 进程会占住端口，导致新实例静默无法绑定（无输出、看似 running）。
4. **实机核验才发现的真缺陷**：REQ-38 的 `projectId: null` vs `'personal'` 属静态审查易漏项，
   实测「按 personal 过滤命中 0 条」才暴露。
